# Виральные Reels на бизнес-темы — еженедельная подборка

Система отслеживает набор Instagram-аккаунтов и раз в неделю выдаёт HTML-дашборд с роликами,
которые **выстрелили относительно собственной нормы автора**, а не просто набрали много просмотров.

## Ключевая метрика

```
outlier = просмотры ролика ÷ медиана просмотров последних 25 роликов этого же аккаунта
```

Ролик с 300K у аккаунта со средними 20K (15×) — сигнал о сработавшем формате.
300K у миллионника — обычный вторник. Абсолютные просмотры входят в итоговый score
с малым весом (степень 0.18), чтобы 15× на аккаунте в 3 тысячи подписчиков не перебивал
всё остальное.

## Установка

```bash
pip install requests jinja2 pillow
export APIFY_TOKEN=apify_api_xxxxx          # apify.com → Settings → API & Integrations
```

## Команды

| Команда | Что делает | Стоимость Apify |
|---|---|---|
| `python viral.py expand [seed1 seed2 …]` | Разворачивает граф похожих аккаунтов на 2 уровня | ~$0.15 за прогон |
| `python viral.py discover` | Ищет новые аккаунты по хэштегам | ~$0.40 за прогон |
| `python viral.py collect` | Забирает свежие reels по watchlist в историю | ~$2.4 на 200 аккаунтов |
| `python viral.py report` | Считает топ и рендерит `out/dashboard.html` | бесплатно |
| `python viral.py run` | collect + report — то, что дёргает планировщик | — |

Порядок первого запуска: `expand` → `collect` → `report`.
Первый `collect` дороже обычного: истории нет, базлайны считаются с нуля.
Со второй недели история накапливается в `data/history.jsonl` и пересчёт идёт по ней.

## Развёртывание на GitHub Actions

1. Создать репозиторий и залить туда содержимое этой папки.
2. Settings → Secrets and variables → Actions → New repository secret:
   имя `APIFY_TOKEN`, значение — токен из Apify.
3. Settings → Pages → Source: **GitHub Actions**.
4. Первый прогон запустить руками: Actions → «Еженедельная подборка виральных Reels» →
   Run workflow, включив галочки `expand` и `discover` — это соберёт watchlist.
5. Дальше воркфлоу сам просыпается по понедельникам в 06:00 по Алматы.
   Дашборд лежит по постоянному адресу `https://<логин>.github.io/<репозиторий>/`.

Галочки `expand` / `discover` имеет смысл включать раз в месяц — состав ниши меняется
медленно, а каждый прогон стоит денег. Еженедельный автозапуск их не трогает.

**Про приватность:** GitHub Pages на бесплатном тарифе работает только с публичным
репозиторием, то есть дашборд будет доступен по прямой ссылке любому, кто её знает.
Токен Apify при этом лежит в секретах и в репозиторий не попадает. Если публичность
не устраивает — делаем приватный репозиторий и отправку дашборда в Telegram вместо Pages.

## Файлы

```
config.json           пороги, watchlist, хэштеги, фильтры релевантности
viral.py              сбор, скоринг, дедупликация, рендер
template.html         вёрстка дашборда (Jinja2)
data/history.jsonl    накопительная история метрик — не удалять, это база для базлайнов
data/accounts.json    отбракованные и автонайденные аккаунты
out/dashboard.html    результат, self-contained, превью зашиты в base64
out/top.json          те же данные машиночитаемо
```

## Настройки, которые имеет смысл крутить

`config.json → scoring`:

- `min_views` (15000) — нижний порог охвата. Поднять, если в подборку лезет мелочь.
- `min_post_age_hours` (36) — ролики моложе полутора суток ещё набирают просмотры,
  их базлайн-сравнение врёт в меньшую сторону.
- `max_post_age_days` (9) — окно недельной подборки с запасом на нахлёст.
- `baseline_min_posts` (5) — сколько роликов нужно, чтобы вообще считать норму аккаунта.
- `top_n` (30) — размер подборки.

`config.json → expand.keywords / stopwords` — тематический фильтр при автопополнении.
Стоп-слова отсекают эзотерику, похудение и казино, которые лезут в бизнес-нишу.

## Ограничения, о которых надо знать

1. **Просмотры отдаются не всегда.** У части аккаунтов Instagram скрывает play count;
   такие ролики выпадают из скоринга — это не баг сборщика.
2. **Обложки протухают.** Ссылки на CDN Instagram живут около суток, поэтому превью
   скачиваются и зашиваются в HTML как base64. Дашборд из-за этого весит 1.5–3 МБ, зато
   работает офлайн и через месяц.
3. **Дедупликация приблизительная.** Один и тот же ролик, разошедшийся по десяти аккаунтам,
   схлопывается по схожести подписи и длительности. Порог `dedup_caption_similarity` (0.82)
   можно ужесточить, если в подборке дубли, или ослабить, если пропадает нужное.
4. **Watchlist деградирует.** Аккаунты закрываются и уходят в приват. Скрипт помечает
   аккаунт мёртвым после двух пустых прогонов подряд и перестаёт тратить на него бюджет.
5. **Серая зона ToS.** Скрейпинг Instagram противоречит его правилам обслуживания.
   Для личного инструмента риск практически нулевой, для публичного продукта — фактор,
   который придётся закладывать в архитектуру.
